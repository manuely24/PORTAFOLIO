# Portafolio de Manuel González

Sitio estático para presentar proyectos web, tecnologías y datos de contacto. Está publicado con GitHub Pages y no requiere backend ni base de datos.

## Contenido

- Perfil profesional y currículum.
- Proyectos con enlaces directos a sus repositorios.
- Diseño adaptable a escritorio y móvil.

## Tecnologías

`HTML` · `CSS` · `JavaScript` · GitHub Pages

## Vista local

Abre `index.html` en un navegador. No hay dependencias ni paso de compilación.

## Publicación

GitHub Pages sirve el contenido de la rama `main`. La imagen destacada está incluida en `assets/` para evitar depender de un host externo.
